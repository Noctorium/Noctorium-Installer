An Experimental page in Settings, with a box for codes -- and every Noctorium is version 0.25.0.

## New

**Settings › About › Experimental.** A place for things that are not settings yet: type a code and press Enter. Codes
are the same on the desktop, the phone and Noctorium Rust, and work in any case.

There is one so far, an easter egg. Try `crash`. (It only closes Noctorium, the way Quit does. Nothing is lost.)

## Worth knowing

- Every Noctorium -- the desktop, the phone, the CLI, Noctorium Stats on both, Noctorium Rust, the web player and the
  installers -- is numbered 0.25.0.
