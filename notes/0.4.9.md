Noctorium now tells you when there is a new version, instead of waiting to be asked.

## The update you never saw

The check has been running at every launch all along. It just had nowhere to say so — the answer went
into a card on the settings screen and nowhere else, which means it only ever reached people who
already suspected there was something to find. Releases have gone out and sat unnoticed.

So it asks, once:

> **Noctorium 0.4.9 is out**
> You have 0.4.8. Do you want to update?
> *Not now — Update*

And then it takes the answer. Nothing counts down. Nothing installs if the dialog is ignored. Closing
it, or tapping away from it, is the same as saying no.

The part that took the most thought is what happens after "Not now". The check runs every time the
application starts, so an offer that came back every launch would not be an offer — it would be the
thing people learn to click away without reading, which is how the one release that actually matters
gets clicked away too. So the refusal is written down, and that version is never raised again. The
next one asks once, as this one did.

Saying no hides the interruption, not the information. The settings card still says a newer Noctorium
exists, because somebody who goes to settings to look is asking.

On a copy that cannot replace itself — an unzipped folder, or a release with no file for that platform
— the button opens the release page instead of pretending it can install anything.

## Nothing else

The player, the volume control that arrived in 0.4.8, themes, accounts, downloads, scrobbling and both
installers are exactly as they were. The packages here are otherwise a rebuild of unchanged code.
