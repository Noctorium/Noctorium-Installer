The Noctorium CLI keeps itself up to date, and the installer is quicker and installs both.

## New

**The Noctorium CLI updates itself.** Once a day, when you start the player or `noctorium web`, it looks
for a newer release. When there is one, it downloads it, checks it against the checksum published with the
release and puts it beside the copy you are using, with nothing to answer. The new copy takes over once
nothing is running from the old one — after you quit, on every system — so nothing changes under music
that is playing.

- `noctorium update` does it there and then, with progress; `noctorium update --check` only says whether
  there is one.
- Settings → *Update automatically* turns it off, and so does `NOCTORIUM_NO_UPDATE=1`.
- Only a copy in your own folders updates itself: the one the installer or the one-line command put there.
  A copy under Program Files, `/usr` or `/opt`, or one you built yourself, says how it should be updated
  instead.

**Both from the installer's window.** Tick Noctorium, the Noctorium CLI or both. The window shows how much
there is to download, gives each its own progress bar and its own result, and says how to start each one
at the end.

## Faster

- **The installer downloads four times as fast.** Each big file comes in four pieces at once, and with both
  ticked, both download together and each installs as soon as its own download is checked. Here, both
  together took 190 seconds before and take 40 now, with the CLI ready after 8.
- **On Windows the installer puts Noctorium in from the .msi**, the way Noctorium's own updater does since
  0.9.1: Windows asks once for permission, a progress bar shows, and there is nothing to click through. An
  update stays in the folder Noctorium is already in. To choose the folder yourself, tick *Choose the folder
  myself* (or use `--wizard`) for the setup's own pages. Close Noctorium before installing over it.
- **Nothing is downloaded twice.** A download that was interrupted carries on where it stopped, and one
  already finished and checked is used again.
- Checking a download against its checksum is about four times quicker.

## Worth knowing

- The CLI's own updates start with this version. A Noctorium CLI from 0.9.1 or earlier needs updating once
  more the way it was installed — the installer, or the one-line command on the website — and keeps itself
  up to date from then on.
- The installer is now 1.3.0. Its terminal version also has `--download-only`, which fetches and checks
  without installing, and `NOCTORIUM_NO_PATH=1`, which installs the CLI without touching your PATH.
- Noctorium itself, on the desktop and the phone, is the same as in 0.9.1; only the number has moved. On
  Windows this is the first update to come the quick way: one permission prompt, a progress bar, and
  Noctorium opens again.
