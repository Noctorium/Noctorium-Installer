## New

**Settings, as the desktop has them.** Noctorium Rust's settings were one long page. They are now what Noctorium for
the desktop has: a home with every page on it under You, Look, Listening, Services, This device and About, each page a
tile that says what it holds and whether it is on, and a search box that finds any one setting — by its name, by what
it does, or by what people call it — and opens its page with it lit up. The twenty-seven pages are the desktop's:
Theme and colours, the player bar, Now playing, Sound, Playback and queue, a page for each service, and the rest.

**Updates that install themselves.** On Windows, Noctorium Rust now looks for a newer version when it starts and every
six hours, downloads it, checks it against the checksum the release publishes, and puts it in place; the new version
opens the next time, or at once from Settings › Updates. Switch it off there to be told instead. On a Mac and Linux it
still runs the installer for you.

## Fixed

- **Windows Defender flagged Noctorium Rust.** Two things it did look like what malware does: its update started the
  installer from the temporary folder through the command prompt, and opening at sign-in added it to Windows' startup
  list through a hidden reg.exe. Neither is done any more: the update is checked and swapped in place with nothing
  else run, and the startup entry is written through Windows' own registry functions.

## Worth knowing

- Every Noctorium — the desktop, the phone, the CLI, Noctorium Stats on both, Noctorium Rust, the web player and the
  installers — is numbered 0.21.1.
- Noctorium Rust 0.21.0 updates to this release the old way, through the installer, once. From 0.21.1 on its updates
  install themselves.
