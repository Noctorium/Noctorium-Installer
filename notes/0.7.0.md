Noctorium in a terminal, Noctorium in a browser, and four more ways to install it on Linux.

## New

**Noctorium CLI.** A music player in the terminal, on the same core as the desktop and the phone: Home,
search, your library and its playlists, the queue, likes on the real account, synced lyrics lit up line by
line, downloads, Connect, every theme and every seek bar style, with the cover drawn right in the terminal.
Driven from the keyboard — `?` lists the keys — or the mouse.

```
noctorium                    the player
noctorium play daft punk     the player, already playing
noctorium search <words>     what both services have, printed
noctorium web                the web player
```

Signing in without a browser to show Google's page: copy the sign-in from Noctorium on the same computer
(`noctorium login youtube --from-desktop`), hand it over from the phone by scanning a code (`--phone`), or
use cookies from any signed-in browser (`--cookies cookies.txt`).

**The web player.** `noctorium web` — or `w` inside the terminal player — serves Noctorium to every browser
on your network: open the link it prints, or scan its code with a phone. Home, search, your library,
playlists you can edit, the queue, now playing with synced lyrics, every setting and theme, a layout for a
phone and one for a computer. The music plays out of whichever device opened the page, with its
lock-screen controls on a phone, or out of the computer's own speakers with the page as a remote. Nothing
runs anywhere but your own computer: the link carries a key, and your sessions never leave it.

**A CLI installer.** `noctorium-installer-cli`, for Windows and Linux, the same installer in a terminal: it
says what it found, asks what to install and how, shows the download as it goes, checks it and installs it.
`--yes`, `--product`, `--format`, `--version` and `--dry-run` for scripts. It installs the Noctorium CLI too,
without admin rights.

**Arch Linux, AppImage and Flatpak.**

- `noctorium-<version>-1-x86_64.pkg.tar.zst` for Arch, Manjaro and EndeavourOS, through pacman.
- `Noctorium-<version>-x86_64.AppImage`, for any Linux, without installing anything.
- `Noctorium-<version>-x86_64.flatpak`, sandboxed, with mpv inside it.

The installers find the right one: pacman on Arch, zypper now works on openSUSE, and anywhere else they
offer the AppImage or the Flatpak. Each updates itself as what it is — an AppImage replaces itself where it
lies — and a Flatpak is told about updates.

## Fixed

- **The phone could take the installer for the update.** The installer's own .apk rides along in every
  release, and nothing stopped the updater picking it. Installers are never the update now.

## Worth knowing

- The Noctorium CLI keeps its things beside the desktop's, in `cli/`, so the two never write over each
  other, and it uses the mpv and yt-dlp the desktop already has.
- On Linux the CLI, the AppImage and the Arch package need mpv from your distribution; the Flatpak carries
  its own. Secrets go to the desktop keyring through `secret-tool` on Linux now, the desktop's included.
- The web player plays YouTube as AAC, which every browser plays, and SoundCloud's streams through hls.js.
