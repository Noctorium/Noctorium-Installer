The lyrics beside the page on the desktop, and songs that start sooner in Noctorium Rust — and every Noctorium is
version 0.22.0.

## New

**The lyrics beside the page.** On Noctorium for the desktop, the player bar's lyrics button used to leave the page
you were on for Now playing. It now opens the lyrics in a panel down the right of the window, beside whatever page is
open, as Noctorium Rust has them: the same lyrics, keeping time with the song, with their sources to switch between.
Drag its edge to make it wider or narrower, and click the button again, or the ✕, to close it. The button is lit
while the panel is open, in every player bar. **Ctrl+L** (Cmd+L on a Mac) opens and closes it too, and can be changed
with the other shortcuts.

## Faster

**Songs start sooner in Noctorium Rust.** Most of the wait between choosing a song and hearing it is finding where
its audio is, which takes a few seconds for a YouTube song. Noctorium Rust now:

- starts finding a YouTube song as soon as the pointer rests on it, so by the time you click it is found or nearly;
- finds each song once: pressing Next while the next song is still being found waits for that rather than starting
  over;
- never keeps a click waiting behind a song being found ahead of time;
- lets the last song's player close in the background, rather than waiting for it before starting the next.

A song you have pointed at for a few seconds, and the next in the queue, now start straight away.

## Worth knowing

- Every Noctorium — the desktop, the phone, the CLI, Noctorium Stats on both, Noctorium Rust, the web player and the
  installers — is numbered 0.22.0.
- Noctorium Rust 0.21.1 installs this release by itself on Windows, unless that is switched off in Settings › Updates.
- On the desktop the lyrics panel starts closed each time Noctorium opens.
