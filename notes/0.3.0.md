Spiceity now installs what it needs to play music, instead of assuming it was already there.

## A fresh desktop install could not play anything

Spiceity uses two separate programs: yt-dlp to find the audio behind a link, and mpv to play it. Neither comes with a desktop, and nothing ever put them on the machine. The first thing anybody saw on pressing play was *"mpv is missing. Install it in Spiceity Settings"* — and Settings had no such page. The one instruction it gave led nowhere.

Now Spiceity fetches them as it starts, with a line across the top saying so and the rest of the application still usable while it happens. There is nothing to answer.

It will not replace an mpv you installed yourself — that copy is found, used and left alone, and Settings → Playback tools says which one is playing. On Linux it does not pretend: there is no portable mpv build, so it prints the `apt` or `dnf` line rather than dropping a binary somewhere and hoping.

**yt-dlp refreshes itself every couple of weeks.** YouTube changes, an old yt-dlp stops working, and that is far and away the most common way a working music player becomes a broken one. It now fixes itself rather than being something you have to know about.

## Also in this release

The version Spiceity reports to Last.fm and ListenBrainz is the version it actually is. It used to be a hardcoded `0.1.0` — true for one release, and the kind of wrong that nothing ever fails on.

Checksums are written in the format the tool that checks them expects. `sha256sum --check` previously refused this file over an extra space, which reads exactly like a tampered download.

## Which file

| Platform | File |
| --- | --- |
| Windows | `Spiceity-0.3.0-windows-x64-setup.exe`, or the `.msi` for deployment |
| Debian, Ubuntu, Mint | `spiceity_0.3.0_amd64.deb` |
| Fedora, RHEL, openSUSE | `spiceity-0.3.0.x86_64.rpm` |
| Android | `Spiceity-0.3.0.apk` |

The desktop packages are around 270 MB because each carries its own Java runtime and its own copy of Chromium for the SoundCloud sign-in window. Nothing has to be installed first — including, now, mpv.

## Verifying a download

```
sha256sum --check --ignore-missing SHA256SUMS.txt
```

## Updating from 0.2.0

Download it from this page. Spiceity's own updater cannot see this release: it asks GitHub's `/releases/latest`, which answers 404 for a private repository, and Spiceity reads that as being up to date.
