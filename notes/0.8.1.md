A fix for quitting on the Mac.

## Fixed

- **Quitting after a sign-in could end in "Noctorium quit unexpectedly" on a Mac.** The sign-in window runs
  an embedded Chromium, and Noctorium ended without waiting for it to finish shutting down, which Chromium
  could crash over on the way out. Quitting now shuts Chromium down and waits for it first — from the menu,
  Command-Q, the tray, closing the window, and the restart after an update. Nothing would have been lost;
  only the message was wrong.

## Worth knowing

- Every Mac release is now also checked for exactly this: Noctorium is started with Chromium running, asked to
  quit, and the release is refused if Chromium is left behind or macOS records a crash.
- Windows and Linux quit the same careful way now, though neither was seen to crash. The phone is the same
  as in 0.8.0; only the number has moved.
