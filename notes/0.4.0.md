Spiceity is Noctorium. Themes, a picture for a mark, and four things borrowed from the clients that do them best.

## The name

Everything is Noctorium now: the window, the installer, the launcher, the account service, the folder your
settings live in. There is no functional difference — it is the same player under a name that is its own.

**On the desktop**, your settings, credentials, downloads, cookie jars and playlists come across by
themselves. The folder has been renamed twice before and the code that carries it over has been exercised
each time; Spiceity's folder is adopted the first time Noctorium runs. The Windows installer replaces the
Spiceity installation rather than sitting beside it.

**On the phone**, it cannot work that way. Android decides what is an update by the application's
identity, and that identity has changed, so Noctorium installs *beside* Spiceity as a separate app.
Uninstall Spiceity once Noctorium is set up. What was on the old one — signed-in services, downloads,
local playlists — does not come with it.

## Themes

Fourteen of them, plus your own. Settings → Customization on the phone, Settings → Theme on the desktop.
The choice is shared, so a theme picked on one is the theme on the other.

| Family | |
| --- | --- |
| Noctorium | Night, Dusk, Day |
| Catppuccin | Latte, Frappé, Macchiato, Mocha |
| And | Nord, Dracula, Gruvbox, Rosé Pine, Tokyo Night, Solarized Dark, Solarized Light |

Light themes are properly light: the window, the title bar, the phone's status bar icons and every
hairline and caption in the interface follow, rather than staying white on white.

A theme is six colours and a switch — the page, a panel, a card, the writing, the muted writing, an accent
— and **Custom** takes those six as the hex values a palette's own README gives you, warning you if the
writing would be too close to the page to read. Every theme that ships is held to the same contrast floor
by a test.

The accent is a separate choice and now defaults to **Theme's own**, so picking a theme brings its accent
with it. Match the artwork, and the named accents, override it as before. *Soft dark*, which used to be
the only alternative to pure black, is now the Dusk theme, and your setting moves across by itself.

## A picture for a mark

The icon in the title bar, on the taskbar, in the installer, on the home screen and beside the name in the
sidebar is artwork now rather than a letter in a gradient box.

## Four things taken from other players

- **Pin to Home** (as SpMp does). A *Pinned* row leads Home, ahead of *Jump back in* and everything the
  services suggest. Pin or unpin from any track's menu.
- **Edit details** (SpMp again). "Artist - Song (Official Video) [4K]" credited to a channel can be
  corrected once, and the correction is what every list, the queue, the player, the notification and the
  scrobbler use from then on. It stays on your device; the service is never told.
- **Skip what is not the music** (as SimpMusic does). On tracks that come from YouTube — never YouTube
  Music, which has none of this — the intros, outros, sponsor reads and talking that SponsorBlock's
  contributors have marked are jumped past. Noctorium asks by a hash of the video id, so the id itself is
  never sent. Each stretch is skipped once; seek back into one deliberately and it is left alone. On by
  default, and switchable.
- **The line being sung, in the player bar** (SpMp). While the lyrics are timed, the bar shows the current
  line where the artist would be. Switchable.

## Which file

| Platform | File |
| --- | --- |
| Windows | `Noctorium-0.4.0-windows-x64-setup.exe`, or the `.msi` for deployment |
| Debian, Ubuntu, Mint | `noctorium_0.4.0_amd64.deb` |
| Fedora, RHEL, openSUSE | `noctorium-0.4.0.x86_64.rpm` |
| Android | `Noctorium-0.4.0.apk` |

The desktop packages carry their own Java runtime and their own Chromium for the sign-in window; the
Windows ones carry mpv and yt-dlp as well, so nothing has to be fetched before the first track plays.
**Close Noctorium before installing over it** — an installer cannot replace files a running program holds
open.

## Verifying a download

```
sha256sum --check --ignore-missing SHA256SUMS.txt
```

The APK is signed with the same release key as every version before it, certificate SHA-256 fingerprint:

```
46:CF:8B:96:C4:37:49:7A:93:AF:76:2B:91:94:AD:11:09:5D:D6:4A:B6:AB:EA:E9:60:C0:A5:98:C5:63:49:ED
```

A debug-signed build already on a phone has to be uninstalled first; Android will not replace it with a
release-signed one.

## Updating

Download it from this page. Noctorium's own updater asks GitHub for the latest release of this
repository, and that request answers 404 while the repository is private — so the updater stays quiet and
reports that you are up to date. It starts working the day the repository is public.
