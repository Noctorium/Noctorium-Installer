Faster updates on Windows.

## Changed

- **Updating on Windows is quicker, and there is nothing to click through.** After you say yes in Noctorium,
  Windows asks once for permission, a progress bar shows while the new version goes in, and Noctorium opens
  again by itself when it is done. Before, the installer unpacked itself all over again, walked you through
  the same pages as the first install, made a System Restore point, and left you to open Noctorium yourself.
- **Your install folder is kept.** If you put Noctorium somewhere other than Program Files, an update now
  stays there instead of moving it back.
- If you say no to the Windows permission prompt, nothing changes and the version you had opens again.

## Worth knowing

- This update itself still installs the old way, wizard and all: the version you have now is the one that
  does the updating. Every update after 0.9.1 is the quick kind.
- The updater now downloads the `.msi` rather than the setup `.exe`. They are the same installer; the `.exe`
  just unpacks the `.msi` before it starts. The setup `.exe` is still the one to download for a first install.
- Linux, the Mac and the phone are the same as in 0.9.0; only the number has moved.
