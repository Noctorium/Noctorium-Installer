Noctorium Rust: Noctorium for the desktop, written in Rust, in every release from this one on — and every Noctorium
is version 0.21.0.

## New

**Noctorium Rust.** The same player as Noctorium for the desktop, as one native program written in Rust: a few
megabytes to download rather than hundreds, starting in a moment, and still playing through yt-dlp and mpv. It has
what the desktop has — YouTube Music, SoundCloud, YouTube, Spotify, Apple Music, Deezer, Tidal, Bandcamp and VK; the
library, playlists and share links; lyrics from every source; Connect; the stream widgets; scrobbling and Discord;
the equaliser and booster; every theme, the Windows 98 and XP skins, every player bar, seek bar and Now playing
layout — and keeps its own settings and library beside the desktop's, reading the desktop's playlists in on its first
run. It comes for Windows, Linux and both kinds of Mac as `noctorium-rust-<version>-…` beside Noctorium Stats.

**The installers offer it.** The window has a fourth box, Noctorium Rust, and the terminal installer takes
`--product rust`, a fifth answer in its menu, and `all` now means all four. The one-line scripts know it too:

```powershell
& ([scriptblock]::Create((irm https://noctorium.vercel.app/install))) --product rust --yes
```

```bash
curl -fsSL https://noctorium.vercel.app/install | sh -s -- --product rust --yes
```

It is installed the way Noctorium Stats is, for you alone and with no password: a folder of its own with a Start
menu shortcut and an entry in Installed apps on Windows, a folder with a menu entry and `noctorium-rust` on your PATH
on Linux, and Noctorium Rust.app in Applications on a Mac. Its own update button runs the installer for it.

## Worth knowing

- Every Noctorium — the desktop, the phone, the CLI, Noctorium Stats on both, Noctorium Rust and the installers — is
  numbered 0.21.0 from here, so a version says which release a program came from.
- Noctorium Rust is new. Signing in to a service from the browser you already use, Spotify and Tidal sign-ins, and
  playing Spotify on Spotify itself were not tried against real accounts before this release; if one of them does not
  work for you, say so in an issue.
- Asked for Noctorium Rust, an installer pointed at an older release leaves it out and says so, and installs
  whatever else was asked for.
